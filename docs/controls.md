# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux) and in the **Keyboard Shortcuts** window (**⌘/** or **Ctrl+/**, or **Help → Keyboard Shortcuts**). That window is built from the same list as the menus, so it is always up to date. Its **Press a Shortcut…** button tells you what any key does without running it.

Single-letter keys only work when you aren't typing in a box.

## Editing

| Action | macOS             | Windows / Linux                |
| ------ | ----------------- | ------------------------------ |
| Undo   | **⌘Z**            | **Ctrl+Z**                     |
| Redo   | **⇧⌘Z** or **⌘Y** | **Ctrl+Shift+Z** or **Ctrl+Y** |

## Events

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New event | **N** or **⌘N**, drag on the grid, or double-click | **N** or **Ctrl+N**, drag on the grid, or double-click |
| Edit the selected event | **↩** or double-click | **Enter** or double-click |
| Delete the selected event | **⌦** or **⌫** | **Delete** or **Backspace** |
| Clear the selection | **Esc** | **Esc** |
| Move the selected event 15 minutes (a week in Month) | **↑** or **↓** | **Up** or **Down** |
| Move the selected event an hour | **⇧↑** or **⇧↓** | **Shift+Up** or **Shift+Down** |
| Move the selected event a day | **←** or **→** | **Left** or **Right** |
| Move an event | Drag it | Drag it |
| Change when it ends, or starts | Drag its bottom edge, or Shift-drag its top edge | Drag its bottom edge, or Shift-drag its top edge |
| Copy it as you drag | Option-drag | Alt-drag |
| Cut, copy, paste | **⌘X**, **⌘C**, **⌘V** | **Ctrl+X**, **Ctrl+C**, **Ctrl+V** |
| Duplicate | **⌘D** | **Ctrl+D** |
| Event menu, or New Event Here and Paste on empty grid | Right-click | Right-click |
| Close the popover | **Return** in the title, **Esc**, or click outside | **Enter** in the title, **Esc**, or click outside |

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New calendar | **⌥⌘N** or **+** beside Calendars | **Ctrl+Alt+N** or **+** beside Calendars |
| Show or hide a calendar | Click its checkbox | Click its checkbox |
| Rename, colour, default, export or delete | Right-click it, or **⋯** on its row | Right-click it, or **⋯** on its row |
| Import an .ics file | **⇧⌘I** | **Ctrl+Shift+I** |
| Show the Trash | Click **Trash** under the calendars | Click **Trash** under the calendars |
| Empty the Trash | Right-click **Trash** | Right-click **Trash** |

## Moving through time

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Previous day, week, month or year | **←** or **K** | **Left** or **K** |
| Next day, week, month or year | **→** or **J** | **Right** or **J** |
| Today | **T** | **T** |
| Show a day | Click it in the mini month or the year | Click it in the mini month or the year |
| Move the day in the mini month or the year (when it has focus) | **←** **→** a day, **↑** **↓** a week, **Page Up** **Page Down** a month, **Home** **End** the week's ends | **Left** **Right** a day, **Up** **Down** a week, **Page Up** **Page Down** a month, **Home** **End** the week's ends |
