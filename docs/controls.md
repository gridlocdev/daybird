# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux) and in the **Keyboard Shortcuts** window (**⌘/** or **Ctrl+/**, or **Help → Keyboard Shortcuts**). That window is built from the same list as the menus, so it is always up to date.

Single-letter keys only work when you aren't typing in a box.

## Editing

| Action | macOS             | Windows / Linux                |
| ------ | ----------------- | ------------------------------ |
| Undo   | **⌘Z**            | **Ctrl+Z**                     |
| Redo   | **⇧⌘Z** or **⌘Y** | **Ctrl+Shift+Z** or **Ctrl+Y** |

## Events

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New event | **N** or **⌘N**, drag on the grid, or double-click | **N** or **Ctrl+N**, drag on the grid, or double-click |
| Edit the selected event | **↩** or double-click | **Enter** or double-click |
| Delete the selected event | **⌦** or **⌫** | **Delete** or **Backspace** |
| Clear the selection | **Esc** | **Esc** |
| Close the popover | **Return** in the title, **Esc**, or click outside | **Enter** in the title, **Esc**, or click outside |

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New calendar | **⌥⌘N** or **+** beside Calendars | **Ctrl+Alt+N** or **+** beside Calendars |
| Show or hide a calendar | Click its checkbox | Click its checkbox |
| Rename, colour, default or delete | Right-click it, or **⋯** on its row | Right-click it, or **⋯** on its row |

## Moving through time

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Previous day, week, month or year | **←** or **K** | **Left** or **K** |
| Next day, week, month or year | **→** or **J** | **Right** or **J** |
| Today | **T** | **T** |
| Show a day | Click it in the mini month or the year | Click it in the mini month or the year |
